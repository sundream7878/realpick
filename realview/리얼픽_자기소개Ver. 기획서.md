## 1. 서비스명

리얼픽 자기소개 Ver.

## 2. 한 줄 정의

리얼예능방송을 보다가 출연자 정보가 헷갈리는 순간, OCR로 빠르게 들어가 전체 출연자의 자기소개 정보를 한 화면에서 확인하는 PWA형 정보카드 서비스.

## 3. 핵심 콘셉트

“누가 누구였지?”를 3초 안에 해결하는 리얼예능 시청 보조 카드.

## 4. 서비스 성격

리얼픽 자기소개 Ver.은 다음 성격을 가진다.

* 리얼예능방송 출연자 자기소개 정보카드
* PWA 기반 모바일 웹앱
* 방송 중 빠른 확인용 서비스
* 출연자 평가가 아닌 기본 정보 제공 서비스
* 공식 채널 유입형 보조 서비스
* 멀린 패밀리앱 생태계의 유입 창구

## 5. 하지 않는 것

리얼픽 자기소개 Ver.은 다음 기능을 하지 않는다.

* 얼굴인식
* 인물 사진 검색
* 댓글 기능
* 출연자 평가
* 루머 정리
* 논란 정리
* 사생활 추적
* 출연자 SNS 기본 연결
* 커뮤니티 악플 유도
* 네이티브 앱 출시

## 6. 주요 사용자 상황

사용자는 리얼예능방송을 보다가 출연자의 이름, 나이, 직업, 지역, 자기소개 내용을 놓친다. 방송은 계속 진행되고, 출연자 간 관계와 선택 흐름은 빨라진다. 이때 리얼픽을 열어 방송 화면 상단의 프로그램명이나 자막을 카메라로 비추면 OCR이 프로그램과 기수를 찾아준다. 사용자는 해당 페이지에서 남녀 출연자 전체 정보를 한 화면으로 확인한다.

## 7. 첫 MVP 범위

첫 MVP는 하나의 대표 리얼예능 프로그램과 한 기수만 대상으로 한다.

MVP 구성:

1. 프로그램/기수 페이지
2. 남자 출연자 전체 카드
3. 여자 출연자 전체 카드
4. 출연자 상세 카드
5. OCR 진입 기능
6. 자기소개 기준 정보 표시
7. 공식 사진 1장
8. 공식 클립/OTT/홈페이지 링크
9. 정보 수정 요청 버튼
10. 하단 띠배너 광고
11. 멀린 패밀리앱 유입 영역
12. PWA 설치 안내

## 8. OCR 기능

OCR은 인물 검색이 아니라 방송 페이지 진입 단축 기능이다.

사용 흐름:

1. 사용자가 리얼픽을 연다.
2. 카메라 버튼을 누른다.
3. TV 또는 모바일 화면 상단의 프로그램명, 기수, 회차, 자막을 비춘다.
4. OCR이 텍스트를 읽는다.
5. 프로그램 후보를 보여준다.
6. 사용자가 선택한다.
7. 해당 출연자 카드 페이지로 이동한다.

OCR 인식 대상 예시:

* 나는 SOLO
* 나는 솔로
* 28기
* 돌싱글즈
* 환승연애
* 솔로지옥
* 하트시그널
* 커플팰리스
* 자기소개
* 첫인상 선택

OCR 결과가 불완전해도 최근 인기 프로그램 후보를 함께 보여준다.

## 9. 메인 페이지 구성

### 상단 영역

* OCR 카메라 버튼

### 프로그램 헤더

* “자기소개 기준”

### 전체 출연자 영역

남자 출연자와 여자 출연자를 한 화면에서 비교 가능하게 배치한다.

각 카드 표시 항목:

* 이름/호칭
* 나이
* 직업
* 지역

* 상세 보기 버튼

### 상세 카드

상세 카드 표시 항목:

* 공식 사진

* 나이
* 직업
* 지역
* 취미/특징
* 자기소개 핵심 내용
* 첫 등장 회차
* 정보 출처
* 공식 클립 보기
* 정보 수정 요청

## 10. 출연자 카드 필수 정보

카드에 반드시 들어갈 정보:

1. 이름/호칭
2. 공식 사진 1장
3. 나이
4. 직업
5. 자기소개 한 줄

가능하면 추가할 정보:

* 지역
* 취미
* 성격 키워드
* 자기소개 핵심문장
* 첫 등장 회차

넣지 말아야 할 정보:

* 추측성 정보
* 비공개 회사명
* 집/직장 세부 위치
* 연애 과거사 추적
* 루머
* 커뮤니티 반응
* 악플성 별명
* 출연자 SNS 링크
* 논란 요약
* 감정선 궁예

## 11. 공식 클립 링크 기준

공식 클립은 방송사, 제작사, OTT, 공식 유튜브 채널에서 제공하는 영상만 사용한다.

공식 클립 유형:

* 자기소개 클립
* 회차별 하이라이트
* 예고편
* 공식 숏폼
* OTT 다시보기
* 공식 홈페이지 회차 클립

비공식 유튜버 리뷰 영상은 공식 클립으로 연결하지 않는다.

## 12. 수익화 구조

초기 수익화는 단순하게 간다.

1. 하단 띠배너 광고
2. 프로그램별 제휴 광고
3. 공식 클립/OTT/유입 제휴
4. 멀린 패밀리앱 내부 유입
5. 추후 방송사 공식 카드 제작 제휴

초기에는 결제 기능을 넣지 않는다.

## 13. 멀린 패밀리앱 유입 구조

리얼픽은 패밀리앱 생태계의 미끼앱 역할을 한다.

유입 방식:

* 우측 또는 하단에 패밀리앱 추천 영역 배치
* PWA 설치 후 다른 앱으로 이동 가능한 허브 버튼 제공
* 리얼픽 사용자에게 다른 앱 소개 카드 노출
* 이벤트형 앱, 투표형 앱, 건강앱, 카페앱 등으로 자연스럽게 이동

단, 리얼픽 본래 목적을 해치지 않도록 광고와 패밀리앱 유입은 하단 중심으로 배치한다.

## 14. UI 방향

현재 리얼픽의 핑크 포인트와 네이비 카드 톤을 유지한다. 기존 미션/픽 구조는 보류하고, 자기소개 정보카드 중심으로 재배치한다.

UI 원칙:

* 한 화면에서 전체 출연자를 빠르게 확인
* 정보는 짧게
* 사진은 작지만 구분 가능하게
* OCR 진입 버튼은 눈에 띄게
* 하단 띠배너 광고만 사용
* 좌우 사이드 광고는 PC에서만 허용
* 모바일에서는 콘텐츠 우선
* PWA 설치 버튼 유지
* 로그인 없이 기본 정보 확인 가능
* 로그인은 픽/저장/이벤트 기능에서만 요구

## 18. 최종 방향

리얼픽 자기소개 Ver.은 리얼예능 출연자를 평가하거나 소비하는 서비스가 아니다. 방송에서 공개된 자기소개 정보를 빠르게 확인하고, 공식 클립과 다시보기로 연결하는 시청 보조 PWA다.

초기에는 작고 빠르게 시작하고, 유입이 확인되면 프로그램을 확장한다. 이후 방송사와 공식 제휴가 가능해지면 공식 제공 이미지와 공식 메타정보를 기반으로 신뢰도 높은 리얼예능 정보카드 플랫폼으로 확장한다.
