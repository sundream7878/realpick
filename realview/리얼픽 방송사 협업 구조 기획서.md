# 리얼픽 방송사 협업 구조 기획서

## 1. 제안 개요

리얼픽은 리얼예능방송 시청 중 출연자 정보가 헷갈리는 순간, 출연자의 자기소개 기반 기본 정보를 한 화면에서 확인할 수 있게 해주는 PWA형 시청 보조 서비스다.

리얼픽은 방송 리뷰, 루머, 출연자 평가, 커뮤니티 논쟁을 다루지 않는다. 방송에서 출연자가 직접 공개한 자기소개 정보만 정리하고, 공식 클립과 다시보기 링크로 사용자를 연결하는 보조 채널 역할을 한다.

## 2. 협업 포지션

리얼픽의 협업 포지션은 다음과 같다.

“리얼픽은 방송사 콘텐츠를 대체하는 서비스가 아니라, 시청자가 방송을 더 잘 이해하고 공식 콘텐츠로 다시 유입되도록 돕는 정보카드 플랫폼이다.”

## 3. 방송사에게 제공하는 가치

### 3-1. 시청 몰입 보조

리얼예능은 초반 회차에 출연자가 한꺼번에 등장한다. 시청자는 이름, 나이, 직업, 지역, 성격, 자기소개 내용을 쉽게 놓친다. 리얼픽은 이 정보를 한 화면에 정리해 시청자가 방송 흐름을 놓치지 않도록 돕는다.

### 3-2. 화제성 확대

출연자 정보카드는 방송 직후 검색 수요와 공유 수요가 높다.

예상 검색 키워드:

* 프로그램명 + 기수 + 출연자
* 프로그램명 + 출연자 직업
* 프로그램명 + 출연자 나이
* 프로그램명 + 자기소개
* 프로그램명 + 남자 출연자
* 프로그램명 + 여자 출연자

리얼픽은 이러한 검색 수요를 공식형 정보 페이지로 흡수하고, 출연자 카드 공유를 통해 방송 화제성을 확장한다.

### 3-3. 공식 채널 유입

각 프로그램 페이지 and 출연자 카드 하단에 공식 클립, OTT 다시보기, 공식 홈페이지 링크를 배치한다.

공식 유입 버튼 예시:

* 공식 자기소개 클립 보기
* 공식 하이라이트 보기
* OTT 다시보기
* 공식 홈페이지
* 공식 예고편 보기

리얼픽은 외부 유튜버 콘텐츠가 아니라 방송사 공식 채널을 우선 연결한다.

### 3-4. 출연자 보호

리얼픽은 출연자의 사생활 추적, SNS 연결, 루머, 악플성 코멘트, 비공식 평가를 제공하지 않는다. 자기소개에서 공개된 정보만 다루며, 출연자 본인 또는 관계자의 정보 수정 요청을 받을 수 있는 구조를 둔다.

### 3-5. 데이터 리포트

제휴 단계에서는 방송사에 다음 데이터를 제공할 수 있다.

* 프로그램별 페이지 조회수
* 출연자별 카드 조회수
* 회차별 유입량
* 공식 클립 클릭수
* OTT 다시보기 클릭수
* 공유 횟수
* 검색 유입 키워드

## 4. 방송사에게 요청할 항목

공식 제휴 시 방송사 또는 제작사에 요청할 수 있는 항목은 다음과 같다.

* 프로그램 로고 사용 허가
* 출연자 공식 프로필 사진 1장
* 출연자 자기소개 기본 정보
* 회차별 공식 클립 링크
* OTT 다시보기 링크
* 공식 홈페이지 링크
* 공개 가능 정보 범위
* 수정 요청 담당 창구

## 5. 리얼픽이 제공할 항목

리얼픽은 방송사에 다음을 제공한다.

* 모바일 최적화 출연자 정보카드 페이지
* 프로그램별/기수별 출연자 전체 보기
* OCR 기반 빠른 진입
* 회차별 스포일러 방지 구조
* 공식 클립/OTT 링크 연결
* 공유용 출연자 카드
* 정보 수정 요청 처리
* 하단 띠배너 광고 영역
* 조회/클릭 데이터 리포트

## 6. 운영 원칙

리얼픽 운영 원칙은 다음과 같다.

1. 자기소개 기반 정보만 제공한다.
2. 출연자 사생활, 루머, 논란, 커뮤니티 반응은 다루지 않는다.
3. 출연자 SNS는 기본 연결하지 않는다.
4. 댓글 기능은 초기 버전에서 제공하지 않는다.
5. 공식 사진은 1장만 사용한다.
6. 사진 출처와 공식 링크를 명확히 표시한다.
7. 요청 시 수정/삭제할 수 있는 버튼을 제공한다.
8. 방송사 공식 채널로 유입되는 구조를 우선한다.
9. 얼굴인식 기능은 제공하지 않는다.
10. 앱 설치보다 PWA 접근성을 우선한다.

## 7. 협업 단계

### 1단계: 비공식 MVP

* 방송에서 공개된 자기소개 정보만 정리
* 공식 사진 1장 사용
* 출처 표시
* 공식 링크 연결
* 정보 수정 요청 버튼 제공
* 하단 띠배너 광고만 운영

### 2단계: 소프트 제휴

* 방송사/제작사에 리얼픽 페이지 제안
* 공식 이미지와 공식 링크 제공 요청
* 공식 클립 클릭 데이터 제공
* 방송사 요청에 따른 문구 수정

### 3단계: 공식 제휴

* 방송사 제공 프로필 이미지 사용
* 공식 제공 정보카드 뱃지 부착
* 회차별 공식 클립 연동
* OTT 유입 링크 연동
* 조회/클릭 데이터 리포트 제공
* 프로그램별 협찬 또는 광고 패키지 운영

## 8. 방송사 제안 문구

리얼픽은 리얼예능 시청자가 출연자 정보를 놓치지 않고 방송에 몰입할 수 있도록 돕는 자기소개 정보카드 서비스입니다. 방송에서 공개된 출연자 기본 정보만 정리하며, 루머나 평가성 콘텐츠는 다루지 않습니다. 각 카드에는 공식 클립과 다시보기 링크를 연결해 방송사의 공식 채널 유입을 돕습니다.

리얼픽은 방송사의 콘텐츠 소비를 대체하는 서비스가 아니라, 시청 편의와 공식 콘텐츠 유입을 높이는 보조 플랫폼을 목표로 합니다.
